Type : spectres Raman MESURÉS, bruts (« Raman Data Raw », « Broad Scan »), échantillons non orientés.
Laser : 532 nm. Plage : environ 86 à 6630 cm-1, un point tous les 1,9 cm-1 environ.
Format : en-tête en lignes commençant par ##, puis 2 colonnes séparées par une virgule
         (décalage Raman en cm-1, intensité), fin du fichier à ##END=.
Pour le projet : graphite massif -> famille « carbone ».
Pics observés : G vers 1584 cm-1, 2D vers 2720 cm-1, D faible.
